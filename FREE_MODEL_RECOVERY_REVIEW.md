# Verified same-provider free recovery

Concrete Kilo free models now enable bounded recovery by default. `--no-rotation` disables it; the previous `--free-model-fallback` flag remains compatible. The gateway automatic alias stays fixed because its concrete upstream is not a pinned catalog route. No provider, account, key, IP, or paid-model rotation is implemented.

Only explicit model-scoped failures qualify. Account/shared/unknown 429 keeps the same route. Candidates must come from the zero-price, tool-advertising catalog, with a known context window at least as large as the current required context. Stale/future cache metadata cannot authorize fallback. Catalog results and shared admission are reused, not probed per model. The next request rebuilds context and reserves output again; current settings/session report the actual destination. Catalog metadata is not proof of live model quality or future pricing.

For explicit Retry-After up to 60 seconds, asynchronous/one-shot work waits with cancellation before one eligible 429 recovery. Long/default cooldowns return a partial report rather than being bypassed. Shared RPM/TPM admission still applies. In synchronous CLI chat, stdin must be read first: the failed turn returns to the prompt; a later user turn may switch only after its new instruction is saved and the cooldown has elapsed. Scope commands take effect before that turn. Pending in-memory recovery does not survive process exit; persisted provider cooldowns, transcript and evidence do. Restart never replays a tool to reconstruct results.

Loopback runtime tests cover model/account/unknown, cancellation, newly submitted instructions and narrowed scope, no suitable free candidate, huge Retry-After, and stale catalog metadata. One approved local counter command is independently checked on disk to execute exactly once across a model transition. That scenario uses four provider requests including a completion-only follow-up, not four commands. Automatic-alias and partial-stream/no-replay tests remain required. These tests are not a live fallback or physical Termux qualification.
