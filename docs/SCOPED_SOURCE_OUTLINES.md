# Single-file structural research for delegates

Alpha's `alphacode_app_core/tool/alphagrep.rs` routes structural outline/search operations, while Blue already has a bounded Tree-sitter parser and a root workspace index. The missing link was access from narrowly scoped independent agents: exposing the whole index would inspect ungranted files even if its output were filtered. `file_outline` instead reuses that existing parser for exactly one canonical allowed file, available to both the parent and delegates. No new parser, workspace scan, command, language server, network operation or child permission is introduced.

The tool reads at most 128001 bytes and rejects files beyond 128000 bytes, NUL/non-UTF8 text, directories, secret aliases and workspace escapes. Size/mtime are checked across the read and cancellation before/after work. A captured complete source digest identifies the content used; it does not guarantee that an external writer cannot change the path afterward. Large files still use the existing bounded windows/search tool.

`kind` selects declarations (default), imports or syntactic calls. Optional `query` is a literal case-sensitive substring of retained item names, up to 100 UTF-8 bytes. `limit` is 1–40, `offset` is 0–2000, and returned rows share a 12000-byte budget. Follow `next_offset`, supplying the previous `source_sha256` as `expected_sha256` on nonzero pages. Changed content is rejected rather than silently combining versions. Row scopes are capped at 240 characters with an explicit truncation flag. Existing parser caps and name truncation remain explicit.

Rust, Python, JavaScript/JSX and TypeScript/TSX use existing grammars. Unsupported extensions return structure_available=false, and parse errors or traversal limits are reported. Empty or partial results never prove semantic absence, reachability, symbol resolution or whole-language completeness. Declared line coordinates refer to the hashed source; tool data and names remain untrusted.

Validation includes language constructs versus fake declarations in comments/strings, imports/calls, hash-bound pagination and changed-source rejection, malformed arguments, parser/output caps, non-UTF8/NUL/oversized sources, cancellation, secret aliases and workspace escapes. The extended real CLI delegate fixture invokes the new tool inside an explicit file grant, rejects another file, retains separate evidence and reconciles output/message quota. This is deterministic local research tooling, not an Alpha runtime benchmark or phone memory/performance certification.
