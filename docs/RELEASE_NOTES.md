Blue Dragon 0.5.0-alpha.2 adds URL-only browser inspection, including automatic Termux browser preparation.

- Run `blue-dragon 'https://example.com'`, `blue-dragon inspect URL`, or paste only the URL in chat/TUI. No browser command, debugging port or pairing token is needed for local Chromium.
- First use on Termux installs official x11-repo/Chromium through pkg. Later tasks reuse the installed browser. Rendering is headless without a graphical session; an existing DISPLAY/Wayland session enables a visible browser. ADB, root and proot are not needed for this path.
- The initial review reads DOM/controls, form structure without values, observed JavaScript source indicators, network metadata, selected CDP security headers and console. It can follow one same-origin registration/login link when the landing page has no form.
- Relevant URL inputs receive at most two fixed benign DOM execution canaries (fragment and one existing search-like query parameter). A random window-property proof is checked; no cookies/storage are read and no data is exfiltrated. Negative checks are not proof of safety; query proof requires further client/server classification.
- Reads in that explicit URL task do not ask for individual confirmations. Form submission/account creation, arbitrary model-provided evaluation and other further interactions retain per-action approval. Static source/sink matches are not confirmed DOM XSS.
- CDP waits for the correct document's DOM-ready lifecycle. Browser evidence is saved in the session before model reasoning. Free model rotation does not replay completed browser actions.
- Regression coverage adds real Chromium URL-only CLI/chat flows, benign DOM proof positive/negative fixtures, no-form-submission checks, security-header filtering and simulated Termux package ordering/reuse.

Physical Android browser verification remains pending. The official Termux Chromium build cannot provide the desktop Chromium sandbox; only the dedicated Termux child uses --no-sandbox with a temporary profile. Desktop launch flags are unchanged. First-use browser downloads may be large; package availability/mirror/device errors are surfaced, not hidden. Firefox developer archives remain unsigned; stock Android Chrome through ADB remains optional. This release does not turn initial source indicators into proven vulnerabilities. See docs/URL_INSPECTION.md and docs/BROWSER.md.
