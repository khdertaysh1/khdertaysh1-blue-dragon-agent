Blue Dragon 0.6.0-alpha.1 improves task control, long-session context and evidence handling around the selected model.

- Task-specific guidance helps distinguish security/browser reviews, diagnosis/fixes and direct engineering questions. It does not replace or upgrade the model weights.
- Provider requests are projected to a context budget while preserving the original transcript and user/system instructions. Older complete tool rounds and large outputs can be excerpted; recall_context retrieves exact original character ranges without repeating actions.
- Context defaults to 32768 tokens including tool/reply reserves. Cached Kilo model metadata may lower it. Explicit context-window errors get one same-provider smaller-request recovery, without tool replay or free-model rotation. /context exposes estimated usage.
- Repeated identical denied/uncertain actions are blocked; unchanged observations prompt another approach and bounded stalled loops stop with evidence saved. Live observations are not replaced with cached output.
- Tool outcomes get evidence IDs. record_finding stores hypothesis/supported/blocked records and rejects invented references or support made only of failures. /findings and session resume preserve these records. Citation validity is not proof of semantic correctness or exploitability.
- Empty final responses after tools get one summary continuation, never a replay of completed tools. Reports include context/loop statistics and unfinished plan counts.
- New offline agent integration cases cover long-context recall, user-constraint retention, denial handling, evidence persistence, empty continuation and context-overflow recovery. Existing browser, installer and all-platform checks remain release gates.

This remains an alpha release. No general model-quality parity percentage or semantic memory graph is claimed. Token estimates are heuristic; oversized essential context still stops explicitly, and existing session loading is bounded to 16MB. Android ARM64 is cross-built; physical-device browser verification remains pending. The existing Termux Chromium sandbox limitation and unsigned Firefox extension distribution are unchanged. See docs/AGENT_REASONING.md, docs/BROWSER.md and docs/URL_INSPECTION.md.
