# Malformed source attribute and element-name correction

Independent review found two correctness gaps in the conservative HTML source collector. A valueless first `src` in `<script src src='/studio.js'>` was not remembered, allowing the second attribute to become a usable source. Separately, element-name scanning stopped at the hyphen, so `<script-x src='/academy.js'>` could be mistaken for a script element; a base-prefixed custom element could also alter discovery resolution.

Both failures were reproduced locally against the actual collector before changing production code. The tests failed on unexpected reference counts. The collector now records the presence of `src` before looking for `=`, rejects repeated attributes regardless of case or value, and marks valueless sources incomplete. It reads the whole element name up to an actual name boundary, so only the exact names `script` and `base` trigger their special behavior. These changes do not claim to implement a full HTML parser.

Regressions cover valueless-first and valueless-second duplicates, mixed case, intervening boolean attributes, valueless-only sources, and script/base-prefixed custom elements. The end-to-end test adds a clearly labeled synthetic response adapter to the unchanged pinned Between Bytes server. With full source scope, the malformed document produces no fetchable references, `limited: true`, one incomplete script tag, and zero dependency GETs. This confirms that scope refusal is not hiding the parsing issue. The normal lab flow still discovers and collects both real scripts in three GETs, and page-only scope still fetches only the page.

Validation: 217 Rust tests, release build, clippy with warnings denied, and three real CLI discovery cases. Results: `validation/discovery-attribute-integrity.json`. Reproduce with `python3 scripts/smoke_source_discovery.py BINARY --lab CHECKOUT`. The normal cases retain an independent HTMLParser oracle; the malformed case checks the explicit conservative duplicate-rejection/exact-name contract and is not a browser equivalence test.

Scope and approval controls were already intact; this fixes source correctness/completeness, not an authorization bypass. No graphical browser, live provider, physical Termux or Windows/macOS runtime was tested. The original lab is unmodified. This independent local follow-up starts from 3f42b4b and includes no upload, merge or release. Report integration was deferred while correcting these review findings.
