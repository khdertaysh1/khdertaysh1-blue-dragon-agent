# Compound and update writes in scoped source flow

Independent review reproduced a correctness gap: `staged += ...` and `staged++` were not included in the candidates counted as writes, so the cached syntax path could keep expanding through `alias` to a later property write with `limited: false`. A local producer-to-flow regression reproduced the failure before changing production code.

The AST collector now records `augmented_assignment_expression` and `update_expression` as `syntactic_update`, including the update argument as the written target. The flow stage counts these alongside simple assignments/declarations. When an update is present in the queried syntax candidates it marks the analysis limited and blocks further identifier expansion; this also covers parameters with no local declaration. Update nodes are never treated as ordinary assignment transformations. Visible use-site candidates remain inspectable with `possible_competing_writes: true`, but later aliases are not automatically followed.

Unit regressions exercise `+=`, `*=`, prefix/postfix increment and updates to function parameters. The actual CLI fixture extends the pinned lab source workflow with two clearly labeled test-only source-response adapters. Each source goes through approved fetch, cached search, the real AST producer and `flow`. Both `+=` and postfix `++` now yield `limited: true`, expose the competing write and stop before following the alias into `innerHTML`. The unmodified lab `/studio-target.js` case still finds and precisely reads the `r` use in `out.textContent`.

Validation: 223 Rust tests, release build, clippy with warnings denied, and three real CLI scenarios. Each scenario performs one local GET and no analysis/read GETs. Source bytes/hashes are checked against the original lab source or the declared synthetic adapter. Results are in `validation/flow-write-integrity.json`; reproduce with `python3 scripts/smoke_scoped_flow.py BINARY --lab CHECKOUT`.

This is not a complete write/alias or control-flow analysis. Destructuring, loop binding effects, block shadowing, object mutation and runtime behavior remain outside the claimed semantic model. No source was executed, and no browser/taint/sanitizer proof is claimed. The original lab is unchanged. The planned cross-file call bridge was deferred while fixing this review finding.
