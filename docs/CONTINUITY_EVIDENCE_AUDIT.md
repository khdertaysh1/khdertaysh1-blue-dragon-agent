## New behavior and limitations

The fresh-source gate is independent of model-declared checks. A final answer without a required fresh local read gets at most one corrective model continuation through normal budgets; it does not itself replay tools. Failed, denied or unknown reads do not trigger an automatic repetition. Missing proof ends one-shot work nonzero with `needs_verification`; interactive chat can continue. Exact `continue`, `go on`, `تابع`, and `كمل` preserve pending checks across turns/restart. A different new request may supersede the active inferred contract; old reports and original messages remain.

A resolved follow-up must cover its prior captured byte interval. An initial request without an explicit machine-readable range proves only the actual nonempty bounded window, not complete analysis. Filename recognition is deliberately limited and must not be described as universal natural-language acceptance. User-derived checks never grant permissions. This change does not automatically verify every quotation, URL, DOM observation or semantic conclusion.

The continuity checkpoint is an extractive, explicitly untrusted index. It contains original message indexes/hashes, bounded historical excerpts, hypotheses and native references. It is neither authorization nor fresh evidence. Original user/system constraints remain verbatim; optional checkpoint sections are dropped with declared omissions before sacrificing mandatory context. No provider call is spent producing it. The full index is local session/model context, available through task_continuity; it is not added to the exported reproduction report because historical excerpts can contain private text. A qualification regression exposed loss of the newest delegate-result IDs during proactive projection. The latest tool batch is now retained intact through proactive tiers; an intermediate tier compacts oversized content while retaining native call/result pairing and evidence IDs. Only subsequent emergency tiers archive completed batches with original-message retrieval pointers; none replays tools. Qualification exposed and fixed both the lost delegate IDs and an oversized-web-result regression. Same-model usage feedback can only tighten a soft projection target; auto-route samples are excluded, and no account capacity is invented.
